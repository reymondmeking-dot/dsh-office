# Self-check before reporting

1. Confirm the main deliverable file exists at the assigned path and is not empty.
2. Re-read the sub-task and the CEO acceptance criteria; tick each one explicitly.
3. If it is code or a page: run it (command line or headless browser) and fix errors.
4. If it is a document: check headings, links, numbers and spelling; remove placeholders like TODO.
5. Report honestly: done / partial / blocked, with what remains and why.
